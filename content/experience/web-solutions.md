Bertanggung jawab atas perancangan arsitektur backend, integrasi payment gateway, sistem keamanan, serta penyusunan dokumentasi teknis standar pada Sistem Reservasi Wisma & Hotel berbasis Laravel 12 dan Livewire Volt.

Tanggung Jawab & Pencapaian Utama:
• Backend & Database Architecture: Merancang skema basis data relasional MySQL teroptimasi menggunakan UUID, relasi Eloquent ORM, dan custom service providers untuk menangani transaksi pemesanan kamar secara atomik.
• Payment Gateway & Webhook Integration: Mengintegrasikan Xendit Payment Gateway V2 (Virtual Account Bank, QRIS, E-Wallet, Retail Outlet) dengan webhook listener asinkronus otomatis untuk rekonsiliasi status pembayaran real-time.
• Multi-Layer Security: Menerapkan Role-Based Access Control (RBAC 3 tingkat: Admin, Peserta Diklat, Umum), rate limiting perlindungan brute-force login, dan proteksi anti-bot dengan Google reCAPTCHA v2.
• Cloud Media Optimization: Mengintegrasikan ImageKit & Cloudinary CDN untuk mempercepat rendering dan kompresi aset gambar kamar secara terdesentralisasi.
• Standardized API Documentation: Menyusun dokumentasi teknis dan spesifikasi API berstandar OpenAPI 3.0 lengkap dengan skema payload JSON, sequence diagram, dan portal interaktif.
• Testing & QA Automation: Membuat skrip pengujian End-to-End (E2E) dan otomatisasi verifikasi sistem menggunakan Playwright.
